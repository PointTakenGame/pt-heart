# Step briefs — one chat each

**The rule: one build step, one fresh chat.** Paste the step's "Prompt" block as your
first message. Do not run two steps in one chat, and do not read ahead into other
step briefs — that is the habit that burned the context window.

Each brief is self-contained: goal, files, the rulings that bind it, a grep done-check,
and the commit message. `CLAUDE.md` loads automatically in every chat; you should not
need to open any other doc unless the brief tells you to.

Between steps, update `../PROGRESS.md`. That file plus the git log is the whole handoff.
